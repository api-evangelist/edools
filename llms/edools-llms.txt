# Edools

> Edools is a Brazilian e-learning / LMS platform for creating, hosting, and selling online courses, learning paths, and training programs under a white-label school. It is now delivered as HeroSpark (edools.com redirects to herospark.com). Edools exposes a token-authenticated REST API on each school's myedools.com subdomain for team, content, and student management, plus first-party Ruby and PHP client libraries and theme tooling.

## API

- [Edools Core API reference](https://docs.edools.com/file.05_api.html): Token-authenticated REST API — base host https://sua-escola.myedools.com/api; auth via `Authorization: Token token="CREDENTIALS"`; version negotiated with `Accept: application/vnd.edools.core.v1+json`.
- [Developer portal (beta)](https://plataforma.edools.com/desenvolvedores): Newer developer documentation surface.
- [Documentation home](https://docs.edools.com): Theme customization and API guides.
